Instalá Clip Studio para la persona que está usando esta sesión. Leé `ONBOARDING.md` y seguilo paso a paso: preguntá cada dato que falte (canal de YouTube, nombre, redes, keys), validá con `npm run setup`, creá la base con `npx vercel integration add neon`, subí el entorno con `npm run push-env` y deployá con `npx vercel --prod`. No inventes valores, no imprimas keys, no saltees la verificación del paso 5.
